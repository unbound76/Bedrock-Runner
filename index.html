How to use Bedrock Runner

A quick guide to every button and what the labels mean.
Help guide

Seed finder

Choose a Bedrock version, run type, difficulty and verification status. Select feature chips to require every checked feature. Search accepts a seed number or words from the notes. Result count limits how many matches are shown.

Find seeds

Applies your current filters and displays matching entries. It does not generate new seeds.

Pick random from matches

Picks one entry at random from the seeds currently matching your filters. It never invents a seed number.

Reset filters

Clears version, run type, difficulty, verification, feature and text filters, and resets the result count to 5.

Copy

Copies that entry's numeric seed to your clipboard. If clipboard access is blocked by your browser, you can still select the number in the card.

☆ / ★ Favorite

Adds or removes the seed from Favorites. Favorites are stored in this browser on this device.

Details

Shows the seed's version, source, status, listed features, notes and source link. Structure coordinates are intentionally not shown.

Submit a seed

Adds a seed to this browser. Choose the version and describe only features you have checked. Select “I tested it in-game” only if you personally tested it. Submissions stay on this device until you export them; they are not sent to GitHub.

Import / export

Export downloads your local library as JSON. Import merges valid entries from a compatible JSON file without adding duplicate seed/version pairs. Clear local library deletes the saved local entries and favorites from this browser.

What do the labels mean?

Verified: marked as checked in-game by the submitter. Unverified: a lead that still needs checking. Community: the entry came from a community source. Official: a source published by the relevant category/tool maintainers. These labels describe provenance; they do not guarantee a fast run.

Important: FSG vs practice starts

The starter library includes community-listed practice seeds, not a complete verified FSG seed bank. The starter library includes 8,298 seed entries from public Bedrock 1.16 FSG seed lists, plus Bedrock 26.3 community-scanned speedrun candidates. Some route candidates have a village, ruined portal, nearby Nether fortress and stronghold according to the linked scan. The imported 1.16 lists preserve their Classic, Ruined Portal and Stronghold pool labels. They are marked unverified because this app has not individually tested every seed. The separate 1.18+ entries are community-scanned practice candidates, not a complete FSG database. The linked FSG generator is the proper place to generate current filtered candidates.
